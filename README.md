# Chehak Miglani — Portfolio

Personal portfolio built with React + Vite. Live at **https://chehakmiglani.github.io**.

## Edit content

All text (projects, experience, skills, links) lives in [`src/data.js`](src/data.js). Change it, push to `main`, and GitHub Actions redeploys automatically.

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Pushes to `main` build and publish via `.github/workflows/deploy.yml`.
One-time setup: repo **Settings → Pages → Source → GitHub Actions**.
